# DoviFuse icon artwork

`DoviFuseIcon.png` is the source artwork for the app icon. It was generated for
this project using OpenAI's built-in image-generation tool on 2026-09-15,
without an input image or an imported third-party logo. The PNG files in

matching the app's processing view. It is not a Dolby logo or certification mark.
The repository's artwork license exclusion still applies.
